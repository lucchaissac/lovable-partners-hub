# Approved composition references

Campaign examples in the root instructions are design constraints, not content to copy into an unrelated request. Private campaign documents, rehearsal conversations and publication records are not distributed in this application handoff.

The portable implementation preserves the approved reusable compositions, original image library, source geometry and editorial memory in:

- `server/communityEditorialMemory.mjs`
- `shared/communityTemplatePlan.mjs`
- `shared/communityTemplateGeometry.mjs`
- `shared/communityStarter.mjs`
- `shared/communityMediaLibrary.mjs`
- `shared/brandTemplates.mjs`
- `shared/brandReview.mjs`

These files retain the useful coordinates, hierarchy, variants, font rules, original artwork and layout relationships. Do not invent missing campaign facts or pretend a private campaign snapshot is bundled. The six original Community masters and their prepared previews remain in the application. Later edits made by a user are authoritative and must not be replaced by a historic example.

For any future Holiday-style or Newsletter-style collection, preserve the specific ordering, native layer composition and export constraints documented in `AGENTS.md`. These rules are not instructions to seed a visitor's browser with another person's saved documents.
