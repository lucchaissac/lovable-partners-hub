Shared designs
Create from an editable source, read its native layers, then save a new version. Shared designs are available to key holders with access to the same workspace.
GET /designsList shared designs
POST /designsCreate a shared design
GET /designs/{id}Read a design and its current version
PUT /designs/{id}Update with the current ETag in If-Match

      
In Make, use Export → Editable source. Upload a single design up to 4 MiB. Chats and links to local collection pages are removed. Sharing creates a new design with a fresh ID.
Connect to view shared designs.
Download this version, import it into Make, edit and export its source. Upload the edited source here to save it back. Local edits are not automatically shared.
A conflicting update is rejected. Read the latest version and reconcile your changes before retrying.

      
The body is { "document": { … } }. Start with GET /example?workspace=lovable, or use an exported editable source. Creation returns a fresh ID; updates must retain that shared ID. Preserve fields and layers you are not changing.
