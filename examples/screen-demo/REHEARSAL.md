# Screen import rehearsal

Local Lovable Make V1, November 20, 2026.

## Direction

Luc’s supplied screen recording sets the import / close-up idea. The stageshow upload and close-up references informed the pacing; the real Make toolbar, chat, editor, Design controls and tokens remain the interface. The screenshot is the actual Lovable Guidelines page. No unrelated product UI or invented conversation is used.

The entry is the existing Image toolbar button: Choose image file or Import from URL. Make editable is on by default locally; turning it off inserts a normal image. The separate sidebar import panel and template-menu entry were removed. A direct local screen-demo route remains available as a prepared example.

The importer reconstructs editable native text, shapes, Lucide icons and source-image regions, grouped for proportional scaling. It does not execute generated HTML or JavaScript. Camera Plain, original Lovable vectors and the shared visual tokens remain authoritative. A new screen preserves the document dimensions, identity and unrelated layers; a later screen replaces the prior component only.
