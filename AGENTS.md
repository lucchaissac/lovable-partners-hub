# Partner hub

- Use Camera Plain from the bundled local font and Lucide for interface icons.
- Use natural sentence case. Never use all-caps typography, uppercase transforms, or small caps.
- Use `#1b1b1b` as the dark background token, with white opacity layers for surfaces and text.
- Match the requested visual scope; navigation behavior will be added when Luc requests it.
- After each requested iteration, verify the build and relevant visual changes, then commit and push to `https://github.com/lucchaissac/lovable-partners-hub.git`. Luc explicitly requested ongoing pushes to this repository.
