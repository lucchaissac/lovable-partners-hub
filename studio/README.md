# Lovable design studio

The “Make your own” tab adapts the supplied Asset Studio editor. It runs in an isolated document at `/studio/index.html`, keeping its React components and styles separate from the hub’s guidelines and badge library.

Run `npm install`, `npm run dev` or `npm run build` from the repository root. The build type-checks the editor and emits both the hub and studio entry points. No separate server or environment variables are required.

The library dropdown inside the editor reuses the eight current partner badges. The editor includes editable text, shapes, Lucide icons images and videos, selection and Design controls, canvas formats, zoom, undo/redo, image/video import (up to 25 MB per video), and `.png`/`.asset.json` export. Camera Plain is embedded in image exports. Video files are embedded in the editable source; PNG exports contain a still frame. The starting composition reuses the gallery’s “Grow your business” artwork as independent editable elements. Designs save locally in the `lovable-partner-designs` IndexedDB database and reopen when returning to the tab.

Community chat runs only with `npm run dev` on localhost. It uses the existing Codex CLI ChatGPT sign-in on this Mac, through a Vite development middleware; it never reads or exposes the account credentials. Run `codex login` first if not already signed in. `COMMUNITY_CODEX_BIN` can point to another installed CLI and `COMMUNITY_CHAT_MODEL` can select an available model. These are server-only settings. The model receives the submitted prompt, recent conversation, current canvas preview and attached references. Generation requires a network connection to Codex; storage and editing remain local.

For a demo, open `http://127.0.0.1:5173/#ambassadors/create` and ask, for example: “Create three square LinkedIn slides for a Lovable Community meetup in Montréal, with our logo, globe and a short headline.” The model can compose custom formats, not just the six templates. A series contains up to six designs, selected with the compact `1 / 3` control in the toolbar. Each design is saved separately with editable native text, shapes, Lucide icons and original Community artwork. Attach images or text with the existing composer. Follow-up edits use the current canvas and selection; Stop, retry and undo remain available. Links are reference text only; this demo does not fetch external pages.

The six gallery masters are supplied as real reference images together with measurements from the source renderer. Every new composition names its reference and adapts that grid to the requested size. Shared checks enforce logo proportions/insets, actual heart-height clear space, the original type hierarchy, dark artwork, globe scale/crop and gradient layer order. The heart is part of the original logo/globe, not a standalone generation primitive. A failed proposal gets one automatic correction before anything reaches the canvas; there is no off-brand fallback. The same validation runs on the server and client. Tests compare reference measurements against the actual renderer.

The [Codex non-interactive runner](https://developers.openai.com/codex/noninteractive) uses an ephemeral read-only session and a strict output schema. Shell tools, connectors and agent delegation are disabled. Responses may contain only the allowed canvas primitives and references to known images; no generated code is executed. The local endpoint checks loopback address, Host, Origin and JSON headers, cancels disconnected jobs and limits request/output sizes. Temporary inputs are removed when the request ends.

`npm run build` and `npm run preview` do not expose this endpoint and keep chat disabled, including on localhost. Partners stays unchanged. The production build contains no provider credentials or local connector. Tests: `node --test tests/*.test.mjs`.

The original reusable components live in `packages/ui` and `src/studio`. `src/lovable.css` supplies the hub’s light and dark tokens and removes borders around the workspace panels. `src/assets-tool/starter.ts` contains the editable Lovable starting design.

Verified in the embedded browser at desktop and narrow widths: library search and badge insertion; local video upload, playback, pause and persistence after reload; PNG export with the video poster and editable-source download; title hover, search focus, header blur, and Design collapse/reopen. The frame stays hidden behind a shell in the active theme until React has painted. The shared theme toggle persists the selected appearance and updates the studio without reloading its canvas. Light mode uses #f7f4ed with black foregrounds. Partners and production keep the Chat composer disabled. Local Community enables it after confirming the Codex connection.
